# きこりんルーム Virtual Tour

PC・スマートフォンで同じURLから開ける、6地点の360°コンセプト内覧です。

- ドラッグ／スワイプで見回し、床の矢印か下部の地点ボタンで移動します。
- 右上の「i」、またはスピーカー位置の「i」でチェーンソーのサンプル音を再生します。
- もう一度「i」を押す、×で閉じる、地点を移動する、別タブへ移ると停止します。
- 下部の「解説を隠す」で説明マーカーを切り替え、「平面図」で地点配置を確認できます。
- 音はクリックしたときだけ再生します。約18秒で終了します。時刻予約式の目覚ましではありません。

窓外は10階・地上約30mからの都会の眺望をイメージしています。きこりんのぬいぐるみをベッドに、BAUMのスキンケアをデスクに配置しています。

BAUMは資生堂のブランドです。住友林業は森林づくりを支援しています。詳細と素材出典は [credits.html](credits.html) を参照してください。

## 音源

現在は社有林の実録ではなく、Joseph SARDIN / BigSoundBank の「Chain saw #0454」（CC0）をサンプルとして使用しています。
https://bigsoundbank.com/chain-saw-s0454.html

## ローカル実行

`project` から `python -m http.server 8765 --directory web` を実行し、http://localhost:8765/ を開きます。ブラウザでJavaScriptとWebGLが必要です。

## 公開・画像について

GitHub Pages向け静的サイトです。閲覧時にアカウント登録は不要です。PC・スマートフォンは画面幅に合わせて表示が変わります。

Web専用の画像編集を使用し、Blenderファイルは変更していません。各画像は1774×887ピクセルの全天球画像です。旧版の8Kレンダ由来のタイルより拡大時の解像感は下がります。生成画像のため視点間で小物や眺望の細部に差があります。実在施設の眺望や正式な提携・商品提供を示すものではありません。
